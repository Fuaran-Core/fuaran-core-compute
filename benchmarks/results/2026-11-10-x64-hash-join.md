# A join's build side of many distinct keys coded by partitions of its values (D69)

Native x64, 32 logical processors, .NET 10, Release.

## The join step, one sitting

`Partitioned.StringJoin`'s data: a left side of `n` rows keyed by `cust-` and seven digits, joined (inner) to a right
side holding each key once, so the build side has as many rows as there are keys. Medians of 41 timed runs after 60
untimed ones, D68 and D69 alternated twice in one sitting:

| Left rows | Keys (build rows) | D68 native | D69 native |
|---:|---:|---:|---:|
| 1,000,000 | 1,000,000 | 78.3, 80.6 ms | 66.1, 70.9 ms |
| 200,000 | 200,000 | 11.5, 12.4 ms | 10.6, 14.3 ms |
| 1,000,000 | 100,000 | 19.1, 19.1 ms | 21.2, 23.0 ms |

The last row's build side is below 131,072 rows and is not partitioned; its probe changed only in coding each range
straight into the output instead of into a copy. A later sitting alternating those two forms read 24.2 and 20.6 ms with
the copies and 23.3 and 21.3 ms without, while the unchanged portable join read 97 and 61 ms in the same runs: the
machine's spread at that time, and no difference between the forms.

The grouping step over a million distinct string keys, whose coding the change refactored, read 26.8 and 27.0 ms before
and 27.3 and 27.7 ms after in the same sitting.

## BenchmarkDotNet

D68 and D69 in two legs of one run:

| Case | D68 | D69 |
|---|---:|---:|
| `StringJoin`, all distinct, 1,000,000, native | 73.3 ms | 59.2 ms |
| `StringJoin`, all distinct, 100,000, native | 5.62 ms | 5.70 ms |
| `StringJoin`, one per ten, 1,000,000, native | 18.9 ms | 19.7 ms |
| `StringJoin`, all distinct, 1,000,000, portable | 152.6 ms | 171.3 ms |
| `StringGroupBy`, all distinct, 1,000,000, native | 26.8 ms | 37.0 ms |

The portable join and the native grouping moved 12 and 38 per cent on code paths the change leaves alone or refactors
without changing what runs; the same-sitting table above reads the grouping level. As in D66, cases that allocate and
collect over a million strings move with the process's heap between legs an hour apart. The keyed family (100,000 rows,
below the threshold) moved within its spread.
